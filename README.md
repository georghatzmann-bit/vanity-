# AEGIS Suite

Eigener moderner Virenschutz + Sicherheits- & Windows-Toolkit für Windows 10/11 (x64).
Tauri 2 (Rust) + React + TypeScript. Rein defensiv.

**Goldene Regel:** AEGIS verändert, verschiebt, beendet oder löscht nichts, bevor du es
ausdrücklich bestätigt hast. Ohne dein „Ja“ wird nur gescannt, gemeldet und erklärt.

Stand und Plan: [`docs/PROGRESS.md`](docs/PROGRESS.md) · Architektur: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
