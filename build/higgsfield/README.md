# Higgsfield-Rohmaterial

Alle Bilder und Clips von HELIX wurden mit Higgsfield gerendert (Bilder: Nano Banana 2 / Z-Image,
Videos: Minimax Hailuo 2.3 Fast). Hier liegen die Originale, aus denen die Dateien in
`src/renderer/assets` und `installer/assets` geschnitten wurden:

| Datei | Verwendung |
|---|---|
| `core.jpg` | Startbild des Kern-Loops, Standbild in der Mitte |
| `core-loop.mp4` | Kern in der Cockpit-Mitte (mit `scripts/loop-video.sh` nahtlos gemacht) |
| `intro-raw.mp4` | Programm-Intro (rückwärts abgespielt + Übergang in den Kern-Loop) |
| `installer-raw.mp4` | Installer-Intro (rückwärts abgespielt) |
| `transition-raw.mp4` | Übergang zwischen Cockpit und Tools (Ausschnitt, 2,5-fach schneller) |
| `bg.jpg` | Hintergrund-Standbild und Startbild des Hintergrund-Loops |
| `planets-sheet.jpg` | 16 Planeten, daraus die Planeten der Tools geschnitten |
| `icon.jpg` | Programmsymbol |
| `spark.jpg` | Startbild des Übergangs |

Die Klänge sind nicht von Higgsfield (dort gibt es im verfügbaren Plan nur Sprache),
sondern werden mit `scripts/make-sounds.py` selbst erzeugt.
