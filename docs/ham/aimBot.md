# aimBot

Toggles aimbot.

## Syntax

```lua
Ham.aimBot(enabled)
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `enabled` | `boolean` | `true` to enable |

## Example

```lua
Ham.aimBot(true)
```
