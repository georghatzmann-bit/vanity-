# copyToClipboard

Copies text to the system clipboard.

## Syntax

```lua
Ham.copyToClipboard(text)
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `text` | `string` | Text to copy |

## Example

```lua
Ham.copyToClipboard("Hello, World!")
```
