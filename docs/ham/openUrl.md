# openUrl

Opens a URL in the default web browser.

## Syntax

```lua
Ham.openUrl(url)
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `url` | `string` | URL to open (must start with `http://` or `https://`) |

## Returns

- `boolean` - `true` if successful

## Example

```lua
Ham.openUrl("https://example.com")
```
