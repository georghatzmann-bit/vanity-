# setPosition

Sets the player's position directly (bypasses normal teleport).

## Syntax

```lua
Ham.setPosition(x, y, z)
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `x` | `float` | X coordinate |
| `y` | `float` | Y coordinate |
| `z` | `float` | Z coordinate |

## Example

```lua
Ham.setPosition(100.0, 200.0, 50.0)
```
