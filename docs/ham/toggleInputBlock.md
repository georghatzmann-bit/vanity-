# toggleInputBlock

Toggles blocking of game input while interacting with overlays.

## Syntax

```lua
Ham.toggleInputBlock(enabled)
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `enabled` | `boolean` | `true` to block game input |

## Example

```lua
Ham.toggleInputBlock(true) -- Block game input
```
