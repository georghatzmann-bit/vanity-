# toggleMouse

Toggles the mouse cursor visibility and control.

## Syntax

```lua
Ham.toggleMouse(enabled)
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `enabled` | `boolean` | `true` to show and enable mouse, `false` to hide |

## Example

```lua
Ham.toggleMouse(true) -- Show mouse cursor
```
