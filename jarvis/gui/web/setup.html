    Willkommen bei Jarvis

    In ein paar kurzen Schritten ist Jarvis startklar. Du klickst nur.

    • MikrofonDamit Jarvis dich hört
    • StimmeWie Jarvis klingen soll
    • Name und OrtDamit Jarvis dich kennt, und für das Wetter
    • GehirnDein Claude-Abo (Pro oder Max): denkt mit, beantwortet Fragen, erledigt Aufgaben
    • ExtrasStumm-Taste, Autostart, Alexa

    Dauert etwa zwei Minuten. Jeder Schritt wird sofort gespeichert.

    Lautstärke–
    „Hey Jarvis“ erkannt–
    Wähl links ein Mikrofon.
    Besser und schneller verstehen gratis Mit einem kostenlosen Groq-Schlüssel erkennt Jarvis Sprache in Bestqualität, meist in unter einer halben Sekunde. So geht's: Groq öffnen, mit Google anmelden, „Create API Key“ klicken, Schlüssel hier einfügen.

    Nur „Jarvis“ sagen, ohne Hey gratis Mit einem kostenlosen Picovoice-Schlüssel reicht auch „Jarvis“ allein. So geht's: Picovoice öffnen, Konto anlegen, den „AccessKey“ kopieren und hier einfügen. Danach oben im Test „Jarvis“ sagen.

    „Hey Jarvis“ englisch aussprechen, etwa „Hej Dschahrwis“. Mit Picovoice-Schlüssel reicht „Jarvis“. Oder Strg + Alt + J drücken.

    ElevenLabs-Schlüssel Konto auf elevenlabs.io anlegen, gratis reicht zum Ausprobieren. Dann „Schlüssel-Seite öffnen“, „Create API Key“ klicken, Schlüssel hier einfügen.

    Eigene Jarvis-Stimme, kostenlos Auf elevenlabs.io unter Voices > My Voices > Add a new voice > Voice Design die Beschreibung und den Probetext einfügen, Generate klicken und die beste Stimme speichern. Danach hier oben Prüfen klicken, dann steht sie unten zur Wahl.
