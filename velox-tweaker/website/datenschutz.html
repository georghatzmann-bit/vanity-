3. Was im Browser gespeichert wird

Die Seite speichert ein paar Einstellungen im lokalen Speicher deines Browsers („localStorage“). Diese Daten bleiben auf deinem Gerät und werden nie an einen Server geschickt:

  • ob du das helle oder dunkle Design gewählt hast,
  • ob der Ton der Startanimation an oder aus ist,
  • auf der BIOS-Checkliste: welche Punkte du abgehakt hast.

Du kannst diese Daten jederzeit löschen, indem du die Website-Daten in deinem Browser löschst. Rechtsgrundlage ist § 25 Abs. 2 Nr. 2 TDDDG (unbedingt erforderlich für die von dir gewünschte Funktion).

4. Die BIOS-Checkliste (bios.html)

Die BIOS-Checkliste öffnest du über einen QR-Code aus der VELOX-App. Die Angaben zu deinem PC (zum Beispiel Mainboard-Modell und BIOS-Version) stehen im Link hinter dem „#“. Diesen Teil eines Links schickt dein Browser grundsätzlich nicht an den Server – er wird nur auf deinem Handy gelesen. Die Seite lädt lediglich die allgemeinen Erklärungstexte von diesem Server nach.

Damit die Checkliste auch ohne Internet funktioniert, legt die Seite die nötigen Dateien im Zwischenspeicher deines Browsers ab (Service Worker). Auch dabei werden keine persönlichen Daten übertragen.
